# Components List

| S.No | Component | Quantity | Purpose |
|---|---|---|---|
| 1 | ESP32 | 1 | Main controller of the system |
| 2 | PIR Sensor | 1 | Detects motion of people or vehicles |
| 3 | LDR Sensor Module (Digital Output) | 1 | Detects day or night |
| 4 | LED | 3 | Works as street lights |
| 5 | Resistor | 3 | Limits current to the LEDs |
| 6 | Breadboard | 1 | Used to make connections without soldering |
| 7 | Jumper Wires | As needed | Connects the components |
| 8 | USB Cable | 1 | Powers and programs the ESP32 |

## Software Used
- Arduino IDE
